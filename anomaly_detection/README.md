# Anomaly Detection — Part 2

This module checks incoming system events for unusual behaviour using the six
metrics generated by Person 1's simulation.

It first builds a baseline from normal events and then compares each incoming
event against that baseline. An event is flagged when one or more of its
metrics goes beyond the calibrated limit.

The anomaly labels in the generated data are only used for testing and
evaluation. They are not used by the detector.
